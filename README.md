### 6. AI Support Ticket Classifier — QLoRA

Fine-tuning project for classifying customer-support tickets using a quantized local language model and parameter-efficient adaptation.

**Dataset:** 12,673 support tickets.

**Recorded evaluation:** 99.68% test accuracy and 99.67% macro F1. Results are from a limited 100-step fine-tuning experiment and should not be interpreted as production performance.

[View Repository](https://github.com/Ahmad-Alqudah/AI-Support-Ticket-Classifier-QLoRA)
